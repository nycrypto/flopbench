# v1.0.0 release checklist

This is the two-person gate for the stable release. `Implementer` is completed
only after local and remote evidence is recorded in the Stage 11 acceptance
report. `User` remains pending until the user reviews that report and explicitly
approves publication.

| Check | Implementer | User |
|---|---|---|
| Stable SemVer and changelog | Pending | Pending |
| Windows and Ubuntu CI | Pending | Pending |
| Unit, contract, security, web, E2E, lint, typecheck, build | Pending | Pending |
| Clean install, use, and uninstall with reports preserved | Pending | Pending |
| Wheel/sdist, SBOM, licenses, checksums, audits | Pending | Pending |
| Miner, validator, benchmark, receipt, and PoUI acceptance | Pending | Pending |
| README commands, links, examples, and demo media | Pending | Pending |
| Draft/provisional/simulated/unofficial labels | Pending | Pending |
| Security contact, privacy, methodology, limitations | Pending | Pending |
| Tag workflow creates attestations before publication | Pending | Pending |

No `v1.0.0` tag or public stable GitHub release may be created while any cell is
pending or failed.
