# FlopBench v1.0.0

FlopBench v1.0.0 is the first stable, independent, local-first readiness and
benchmarking workbench for future FLOP participants. It is not an official FLOP
Labs or Flop Foundation product, miner/validator client, eligibility checker,
claim tool, or reward guarantee.

## Highlights

- Passive Windows/Linux CPU, memory, disk, NVIDIA, AMD-safe-fallback, and CPU-only
  probing with private/support/public disclosure modes.
- Explainable miner/validator checks against the versioned `flop-teaser-0.1`
  draft source profile; the profile remains provisional and does not confer
  eligibility.
- Consent-gated validator health tests and deterministic mock, Ollama, and
  OpenAI-compatible benchmark adapters.
- Offline JCS reports, redaction, comparison, and external Ed25519 `did:key`
  receipt verification without private-key custody.
- Bilingual, accessible, orange-accented local dashboard and deterministic PoUI
  teaching simulation with mock-only accounting.
- Windows/Ubuntu verified wheel and sdist with SHA-256 checksums, CycloneDX SBOM,
  license inventory, dependency/secret audits, and GitHub build provenance.

## Known limitations

The 16 GiB miner VRAM value is a sourced draft profile threshold. An 8 GiB GPU is
expected to fail that readiness check while remaining usable for suitably small
local models. Hardware/runtime self-reports are not independently trusted. No
official testnet adapter is included; Stage 12 remains blocked on a public,
versioned official contract. See [all limitations](../limitations.md).
