# FlopBench dashboard demo

[Download the local dashboard walkthrough](./assets/flopbench-dashboard-demo.webm).

The recording uses only deterministic fixtures. It shows the English overview,
miner readiness, mock benchmark, public-report preview, and simulated PoUI flow.
No live hostname, user name, path, token, model response, wallet, claim, reward,
or official eligibility result appears in the media.

The dashboard itself remains local-only at `http://127.0.0.1:4173`; this media is
not a hosted product demo. The user can switch between English and Turkish and
between light/dark preferences in the local interface.
