# ADR 0002: Project identity and license

- Status: Accepted
- Date: 2026-08-29

## Decision

The repository and package name is `flopbench`. It is an independent, community-built project licensed under Apache-2.0. English is the primary documentation language and Turkish is the secondary language.

Every primary entry point must state that FlopBench is not an official FLOP Labs or Flop Foundation product and is not an eligibility or claim tool.
