# FlopBench v1 examples

The files in [`reports`](./reports) contain synthetic, deterministic, public-safe
examples generated by `python scripts/generate_examples.py`. They are not live
measurements, official scores, identity proofs, eligibility decisions, or reward
claims.

- `miner-readiness.public.json`: source-profile miner readiness.
- `validator-readiness.public.json`: source-profile validator readiness; its
  network check remains skipped until an active test is approved.
- `mock-benchmark.json`: deterministic simulated benchmark metrics.
- `agent-simulation.json`: normal mock PoUI lifecycle.
- `agent-validator-challenge.json`: rejected validator-mismatch teaching path.
- `public-readiness-report.json` and `.html`: the same redacted report envelope;
  the HTML has no scripts, network requests, or external resources.

Regenerate and verify byte identity:

```powershell
python scripts/generate_examples.py
python scripts/generate_examples.py --check
```
